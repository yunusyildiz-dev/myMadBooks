## Neden TypeScript?

JavaScript güçlü bir dildir — ama dinamik tipler büyük projelerde ciddi sorunlara yol açar. TypeScript, JavaScript'e **statik tip sistemi** ekler ve şunları sağlar:

- Hataları **runtime'dan önce** compile-time'da yakala
- IDE'nin seni **otomatik tamamlasın**, yanlış kullanımları **anında göstersin**
- Ekip içinde **okunabilir, bakımı kolay** kod yaz
- Geleceğin JavaScript özelliklerini **bugün** kullan
